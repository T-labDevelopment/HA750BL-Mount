# 検査記録 Rev.A（2026-10-21）

## 実施済み

- メーカー製品ページと取扱説明書を目視確認。コネクタ形式：M-P、フィン＋底面エアダクト、折曲機構があることを確認。
- CADは OpenSCAD 2021.01 で4種のSTLへ出力。出力時CGALにて3Dソリッドとして構成。
- trimeshで4ファイルすべて `is_watertight = True` と確認。
- STL寸法・体積の機械的検査を実施。下側部品の最大長さ約165.2 mm。φ32mmポールの場合。

## 未実施（要現物合わせ・試験）

- φ28が固定金属スリーブか、M-Pの回転カップリングかの確認。
- ポール径の確定、フィン実外径、φ16/φ28部の長さ、取付箇所の間隔。
- 打出し試作、M5ボルトの入り、PETGの穴寸法精度、上下のガタ・締付力。
- 実機取付状態での強度・風荷重・長期クリープ・熱の評価。
- 同軸接続や折曲動作、底面エアダクトへの干渉・アンテナのVSWR変化。

**判定:** CAD幾何検査済み／プリント未実施／実機未検証／屋外常設への使用判定不可。
