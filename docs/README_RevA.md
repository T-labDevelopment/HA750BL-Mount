# COMET HA750BL φ16/φ28 ポール固定ブラケット Rev.A

作成日: 2026-10-21  
状態: **仮寸法に基づく3Dプリント試作・現物合わせ前**（屋外常設使用の強度保証なし）

## 設計対象と根拠

- 対象アンテナ: COMET HA750BL（公式製品ページ https://www.comet-ant.co.jp/product/1316/ ）
- メーカー公称の全長約2.41 m・質量約820 g、給電部は放熱フィンと底面エアダクトあり。
- ユーザー提供実測目安: 上部エレメント側外径 **φ16 mm**、下部同軸側外径 **約φ28 mm**。
- ポール外径は未指定。設計例 **φ32 mm** とし、OpenSCAD変数で変更できる。
- 給電部外周直径・上下保持部分の軸方向間隔・φ28部の固定/回転の別は**未確認**。
- 例示画面に使った給電部直径φ55 mmと上下ブラケット高さ差180 mmは**未計測の模式表示**であり、設計値・メーカー公表寸法ではない。

## 構造

上下2個の独立型「ポール＋アンテナ」横架橋分割クランプ。各ホルダーは基台側/押さえ側の2部品構成、M5ねじ3本で閉じる。

1. 下側（青）: φ28 mm部を保持するクランプ。軸方向接触高さ22 mm。機械的に固定された平滑な円筒部のみを保持する。
2. 上側（緑）: φ16 mmエレメントを**軽く位置決めするガイド**。穴に直径方向1.2 mmの余裕を設定し、エレメントは金属クランプで締め付けない。軸方向接触高さ18 mm。
3. 左側は共通のポールにそれぞれクランプ。上下ブラケット間隔はポール上の取付位置で自由に調整可能。
4. ポールとアンテナの軸間は例示で88 mm（`center_spacing`）。給電フィンをポールに接触させないため、給電部実外径に応じ調整する。

### 重要な使用条件

- **アンテナのM-P型コネクターの回転ナットや、同軸ケーブル自体をφ28クランプで固定しない。** φ28 mm部分が回転部であれば本設計は使用できず、M-J金属基台を構造支持とする別案へ変更する。
- φ16 mm部分はRFエレメントである可能性があり、強く締め付けない。配置変更によるSWR変化を測定する。
- 給電部のフィンや底面エアダクトを覆わず、折曲機構の可動範囲を妨げない。
- 約2.41 mのアンテナは風による曲げ荷重が大きい。**PETG樹脂クランプのみで全重量や強風に耐える設計とは評価していない。** 屋外常設ではM-J金属基台・Uボルト式金具等の一次荷重支持を併用し、3Dプリント部品は横振れを抑制する補助ガイドに限定する。
- 取付高さ、ポール強度、ねじ緩み、落下防止、送信時温度上昇等は実機で確認すること。

## 例示パラメータ（単位 mm）

| 変数 | 初期値 | 意味 |
|---|---:|---|
| `pole_diameter` | 32 | ポール実外径（変更必須） |
| `lower_antenna_diameter` | 28 | 下側の**固定された**円筒外径。概測 |
| `upper_element_diameter` | 16 | 上側のエレメント外径。概測 |
| `center_spacing` | 88 | 両中心間隔。給電部サイズで再調整 |
| `lower_height` | 22 | 下部保持長。現物の直線長で調整 |
| `upper_height` | 18 | 上部ガイド長 |
| `upper_position` | 180 | 3D模式画面専用。上下個別設置なので印刷形状には無関係 |
| `split_gap` | 1.2 | 分割面の組立時すき間 |
| `lower_diametric_clearance` | 0.25 | φ28部の公称穴径上乗せ量 |
| `upper_diametric_clearance` | 1.2 | φ16部のガイド穴径上乗せ量 |

**注意:** φ28 mmは「約」なので、現物寸法が28.5 mmなら変数も28.5に変更する。

## ポール径に合わせた編集方法

OpenSCADを開き、`pole_diameter = 32;` を実際のポール外径へ変更する。必要なら `center_spacing` も調整。
`part` を `lower_base` / `lower_cap` / `upper_base` / `upper_cap` に変更し、F6で3D計算、STLへエクスポートする。
`print_orientation = false` が推奨。ブラケットの広い平面（Z=0）をベッドに置く。

## Bambu Lab A1 / PETG 試作条件（初期提案）

- 0.4 mmノズル、積層0.20 mm、壁5周、インフィル40～50 %、サポートは原則なし（M5横穴のブリッジ精度を確認）。
- ねじ穴・ナット収納部の実寸は造形後に測定し、M5を無理にねじ込まない。
- ねじはステンレスM5×25程度×6本、M5六角ナット×6個を想定。ボルトの有効長、座ぐり深さ、ナット寸法を現品で確認する。
- 締付トルクは未評価。樹脂の割れや変形が発生しないよう段階的に締める。
- 押さえと被保持物の間にごく薄いEPDMテープを挟む場合、厚みに合わせて穴径・クリアランスを再設計する。

## 強度評価が必要な理由

本品は初期寸法と組立干渉を見るためのCAD試作です。実アンテナの重量支持・風荷重・紫外線劣化・長期クリープ・給電部温度について計算/試験を済ませておらず、設置可能な完成品とは判断できません。
