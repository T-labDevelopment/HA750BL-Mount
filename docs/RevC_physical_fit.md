# Rev.C — 現物写真に基づく設計改訂 (2026-10-23)

## 確認された失敗

ユーザーの実機組立写真では、長い放熱フィン付き給電部がRev.Bの保持用支柱に干渉し、φ28側の固定部とφ16側のガイド位置が合わない。Rev.Bで仮定した保持穴中心間隔172mmは短すぎた。必要な**正確な**長さは未測定で、写真からの画素換算を実寸とは扱わない。

COMET公式: https://www.comet-ant.co.jp/product/1316/ （フィン・底面エアダクト、全長約2.41m、約820g）。

## 解決策

- 上下を独立したL型樹脂保持部に分離。それぞれ**M6 Uボルト1本**で同一ポールへ取り付け、組立状態でコの字型になる
- 上部φ16は貫通ガイド（初期穴径φ17.2）、エレメント近傍に金属締付具は設置しない
- 下部約φ28はRev.Bと同寸法のM4熱圧入ナット2個付き押さえ板を使用。元のRev.B押さえ板は再利用可能
- 中央の樹脂橋渡しプレートは別造形。M5熱圧入ナット4個とM5ボルト4本で上下L型を連結する。Uボルトと干渉しない位置にねじを配置
- 初期の保持穴中心間隔280mmは**造形確認用の仮設定**。まず上下を単独でポール上に位置合わせし、φ28とφ16の保持中心面間距離を実測してから `support_center_spacing` を修正し、橋渡しプレートを再造形
- 樹脂製の2つのL型保持部は長さを変えずに使用できる。現在の橋渡しプレートの設計範囲は中心間230～340mm

## 検証と注意

**CAD検証:** OpenSCADから各STLを書き出し、単一の閉曲面で、256mmのA1造形領域内に入ることを機械的に確認。下部押さえ形状はRev.Bと一致。

**未検証:** 実際に必要な保持中心間隔、給電フィン径と長さ、ポール実径、Uボルト実寸、熱圧入ナット製品、PETGでの嵌合・締付強度、風荷重、長期クリープ、放熱、落下防止、送信SWR。

**重要:** 約φ28の部分が回転する同軸コネクターナットなら締め付けてはならない。屋外常設には独立した金属支持・二次落下防止および強度評価を検討すること。CADメッシュ検査は強度保証ではない。
